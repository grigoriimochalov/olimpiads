# Olimplist — каталог перечневых олимпиад

Индивидуальный проект: веб-сайт, собирающий сроки, уровни и льготы перечневых
олимпиад школьников (перечень Минобрнауки 2026/2027) в одном месте.

## Запуск локально
Сайт читает `data/olympiads.json`, поэтому открывать его нужно через локальный
сервер (при открытии файла напрямую браузер блокирует fetch — в этом случае
сайт автоматически использует встроенную резервную копию данных):

    python -m http.server 8000
    # затем открыть http://localhost:8000

## Структура
- `index.html` — разметка + встроенный резервный набор данных;
- `css/style.css` — оформление, светлая и тёмная темы, адаптив 360–1920 px;
- `js/app.js` — фильтры, поиск, сортировка, карточка-шторка, избранное,
  сохранённые виды, экспорт дедлайнов в `.ics`, статус обновления;
- `data/olympiads.json` — данные каталога; их обновляет парсер
  (`scripts/parser.py`) по расписанию GitHub Actions каждые 12 часов;
- `.github/workflows/update.yml` — cron-запуск парсера и коммит JSON.

## Деплой
Settings → Pages → Deploy from a branch → `main` / root.
Сайт публикуется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Данные
Стартовый набор каталога приведён для запуска интерфейса; боевые данные
формирует парсер из официальных источников (rsosh.ru и сайты олимпиад).
Все выводимые строки экранируются, ссылки принимаются только по https.
